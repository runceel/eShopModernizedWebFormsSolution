# 移行先仕様: 受け入れ基準

合意済みの仕様を確認するための条件であり、実装や検証が完了したことを示さない。未決定事項は合否条件を仮決めせず、関連 Issue で確定する。DB リセットや失敗注入は、対象を確認したローカルのテスト環境でのみ実施する。

## 起動・データ

| ID | 操作・条件 | 期待結果 |
|---|---|---|
| AC-01 | 組み込みデータ設定の未初期化 DB で `aspire run` | DB のスキーマ作成・データ投入後、API と Web が利用可能になる |
| AC-02 | AC-01 のデータを確認 | ブランド 5 件、タイプ 4 件、商品 12 件。組み込み商品 ID は 1〜12 で、各 ID の内容は [現行初期データ](../current-spec/04-data.md#44-初期データ) と一致する |
| AC-03 | 初期投入後に商品を作成 | 既存商品と重複しない ID が採番され、画像名は `dummy.png` |
| AC-04 | 商品の作成・編集後に通常停止し、再度 `aspire run` | 変更したデータと利用する画像が残り、初期データは重複しない |
| AC-05 | 全商品を削除して停止・再起動 | 商品は 0 件のまま。再起動を理由に再投入されない |
| AC-06 | CSV・画像 ZIP を選択し、未初期化 DB で起動 | 選択した入力に従ってカタログデータと画像が初期化される |
| AC-07 | CSV・画像 ZIP を選択し、必要な入力を不足または不正にして初回起動 | エラーを通知し、通常操作を受け付けない。組み込みデータへ自動で切り替えない |

## 画面・互換性

| ID | 操作・条件 | 期待結果 |
|---|---|---|
| AC-08 | `/`、`/Default`、`/Default.aspx` にアクセス | URL を変更せず一覧を表示。組み込み初期データでは ID 1〜10 を表示 |
| AC-09 | `/Default/index/1/size/10` にアクセス | ID 11〜12 を表示し、一覧のページ移動ができる |
| AC-10 | 既存の登録・詳細・編集・削除 URL、および `/Catalog/Create.aspx` にアクセス | 対応する画面を表示し、正常な登録・編集・詳細表示・削除と一覧への復帰ができる |
| AC-11 | `/Catalog/Details.aspx`、`/Catalog/Edit.aspx`、`/Catalog/Delete.aspx` に ID なしで直接アクセス | それぞれ HTTP 500。レスポンスに内部例外やスタックトレースを含めない |
| AC-12 | `/About.aspx`、`/Contact.aspx`、`/Pics/1.png` にアクセス | URL を変更せず、対応する現行の静的内容・画像を表示する |
| AC-13 | Name を空欄、または Price / 在庫項目に範囲外の値を入力して保存 | 現行の該当メッセージを表示し、データを保存しない。クライアント側の検証を回避してもサーバー側で拒否する |
| AC-14 | HTML / スクリプトを含む文字列を登録して詳細・削除画面に表示 | 文字列として表示され、スクリプトが実行されない |
| AC-15 | `OnReorder=true` の商品を編集して保存 | 画面にない `OnReorder` は `true` のまま |
| AC-16 | 2 人が同じ商品を編集し、先に保存した後で古い内容を保存 | 後からの更新を拒否して競合を通知し、先の変更を保持する |
| AC-17 | 同一セッションで画面を移動 | フッターに Web ホストのマシン名と同じセッション開始時刻を表示する |

## 明示的な DB リセット

| ID | 操作・条件 | 期待結果 |
|---|---|---|
| AC-18 | Aspire のリセットコマンドで確認をキャンセル、または確認なしで実行 | DB と画像を変更しない |
| AC-19 | 組み込みデータの設定でリセットを確認 | 商品・ブランド・タイプが組み込み初期状態になり、商品 ID 1〜12 を保持する。その後の新規 ID は重複しない |
| AC-20 | CSV・画像 ZIP の設定を有効にしてリセットを確認 | **その時点で有効な設定**の CSV・画像 ZIP を使用する。以前の初期化時に使ったデータを固定的に再利用しない |
| AC-21 | CSV・画像 ZIP を指定し、必要な入力を不足または不正にしてリセット | エラーを通知し、消去・画像更新を開始しない |
| AC-22 | 選択した画像セットに含まれない既存画像を用意してリセット | セットに含まれる画像だけが更新され、含まれない画像は残る |
| AC-23 | リセット処理中にカタログ操作を試みる | 通常操作は受け付けられず、一時利用不可と通知される。成功後に利用を再開できる |
| AC-24 | 検証後の DB・画像更新中に失敗を発生させる | 失敗を通知し、開始前の状態への復旧を試みる。復旧できない場合や状態不明時は、再起動後も復旧が確認できるまで通常操作を停止したまま通知する |

リセットコマンドの具体的な名前・確認引数、競合時の API 応答、その他の異常時ステータス、テストの自動化範囲は未決定。
