# 移行先仕様: 既知事項の処置

[現行の KI-01〜20](../current-spec/06-known-issues.md) に対する [OD-10](https://github.com/runceel/eShopModernizedWebFormsSolution/issues/11) の整理。これは設計・受け入れ条件であり、実装や検証の完了を示さない。第 1 ゴールはローカル利用で、見た目以外の現行挙動を維持する。ただし合意済みの安全性・データ保護上の例外を適用する。既存 SQL Server 実データの移行は対象外。

「修正」は現行の問題を再現しないこと、「維持」は観測可能な挙動を維持することであり、内部例外やスタックトレースの表示を維持する意味ではない。「第1ゴール対象外/後続判断」は未決定であり、安全と判断したことを意味しない。未確認の現行挙動は実機で基準を確認する。下記の検証は実装後に行う。

## 後続の実装・検証の分割案

既存 Issue を増やさず、実装開始時に次の単位を検討する: 画面互換性と安全なエラー（KI-01〜05、09、12、19、20）、API 入力・編集競合（KI-06〜08、11）、永続化・初期化・画像保護（KI-13、15、17、18）、認証境界・CSRF と運用観測（KI-10、14）。KI-16 は初期化の診断に含める。分割は提案であり、実装 Issue の作成や完了を意味しない。検証は OD-17 の単体、実 PostgreSQL API 統合、隔離 AppHost 構成、少数のブラウザー回帰で分担し、破壊操作を開発用データに向けない。
